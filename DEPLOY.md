# Публикация и видео

## Коротко

- **Сайт** — GitHub → Vercel. Статика, бесплатно, деплой по пушу.
- **Видео** — Selectel Object Storage + CDN, **в аккаунте клиента**. Он платит за
  своё хранилище и трафик, вы к его счетам не привязаны.
- Связывает их одна строка в `assets/config.js`.

Почему видео не на Vercel: бандвич там считается на аккаунт владельца проекта.
Видео на первом экране скачивается каждым посетителем, и это тот трафик,
который выедает лимит первым. На Free-плане это ещё и запрет на коммерческое
использование. Кладя видео в Selectel клиента, вы одновременно снимаете
и оплату, и юридический вопрос.

## 1. Сайт на GitHub

```bash
cd site
git init
git add .
git commit -m "Главная: вёрстка по DESIGN.md"
git branch -M main
git remote add origin git@github.com:<логин>/troyanovsky.git
git push -u origin main
```

Репозиторий лучше сразу завести **в аккаунте клиента**, а вас добавить
коллаборатором. Тогда при передаче проекта ничего не переносится.

## 2. Сайт на Vercel

1. vercel.com → Add New → Project → импортировать репозиторий.
2. Framework Preset: **Other**. Build Command и Output Directory — пустые:
   сборки нет, отдаётся корень как есть. `vercel.json` уже в репозитории.
3. Deploy. Дальше каждый пуш в `main` выкатывается сам.
4. Домен: Settings → Domains → добавить `troyanovsky.com` (или какой купите),
   у регистратора прописать A-запись `76.76.21.21` или CNAME на
   `cname.vercel-dns.com`. Vercel выдаст точные значения и сам оформит TLS.

Альтернатива без Vercel — GitHub Pages: Settings → Pages → Branch `main`, папка
`/`. Файл `.nojekyll` уже лежит, он нужен, чтобы Pages не съел служебные пути.
Vercel предпочтительнее из-за нормальных заголовков кэша и preview-деплоев на
каждую ветку.

## 3. Видео в Selectel — за счёт клиента

Делается **в аккаунте клиента**. Заводите его сами под его почтой и картой либо
просите зарегистрироваться и добавляют вас пользователем с правами на
объектное хранилище.

### 3.1. Контейнер

1. my.selectel.ru → Облачная платформа → **Объектное хранилище** → создать контейнер.
2. Имя, например `troyanovsky-media`. Тип доступа — **публичный**.
   Приватный потребовал бы подписанных ссылок, а видео на главной публичное
   по смыслу.
3. Класс хранения — «Стандартный».

### 3.2. Загрузка

Через веб-интерфейс: открыть контейнер → Загрузить → выбрать `hero.webm`
(и `hero.mp4`, если сделаете, см. 3.4).

Или через S3-совместимый API, если файлов станет много:

```bash
# Ключ создаётся в разделе «Пользователи и роли» → S3-ключи
aws --endpoint-url=https://s3.ru-1.storage.selcloud.ru \
    s3 cp hero.webm s3://troyanovsky-media/hero.webm \
    --content-type video/webm --cache-control "public, max-age=31536000, immutable"
```

`Cache-Control` важен: без него CDN и браузеры перекачивают видео чаще, чем
нужно, и трафик клиента растёт на ровном месте.

### 3.3. CDN

1. В панели: **CDN** → создать ресурс, источником указать контейнер.
2. Selectel выдаст адрес вида `https://<id>.selcdn.ru` или разрешит привесить
   свой поддомен, например `media.troyanovsky.com`.
3. Скопировать полный адрес файла.

CDN нужен не ради экономии, а ради скорости: видео на первом экране начинает
играть с ближайшего узла, а не из одного дата-центра.

### 3.4. Подключить к сайту

`assets/config.js`:

```js
window.SITE_CONFIG = {
  heroVideo: "https://media.troyanovsky.com/hero.webm",
  heroVideoMp4: "https://media.troyanovsky.com/hero.mp4",
  heroVideoFallback: "video/hero.webm",
  heroPoster: "img/hero-poster.jpg"
};
```

Это единственная правка. Скрипт пробует адреса по порядку и уходит на следующий,
если файл не отдался, — при упавшем CDN страница играет запасной файл из
репозитория, а не показывает чёрный прямоугольник.

`hero.mp4` (H.264 + AAC) стоит сделать: WebM не играет в Safari до 16 и в части
старых Android. Из исходника:

```bash
ffmpeg -i hero.webm -c:v libx264 -crf 24 -preset slow -an \
       -movflags +faststart hero.mp4
```

`-movflags +faststart` кладёт индекс в начало файла — без него видео начинает
играть только после полной загрузки.

## 4. Приём заявок

Форма заявки — `/zayavka.html`. Пока `SITE_CONFIG.bookingEndpoint` пуст, она
проходится целиком и показывает все состояния, **но никуда ничего не
отправляет**: в консоли остаётся предупреждение, а человек при этом видит экран
«Спасибо. Я прочитал». До публикации endpoint обязателен — иначе заявки
теряются молча.

Что нужно:

1. Приёмник, отвечающий на `POST` с JSON:

   ```json
   { "type": "love", "city": "spb", "date": "2026-10-22",
     "slot": "golden", "name": "Аня и Кирилл",
     "contact": "@annakiroff", "about": "Познакомились в очереди на Ван Гога" }
   ```

   Подойдёт Vercel Serverless Function (`api/booking.js` в этом же
   репозитории), Formspree, Getform — что угодно, что кладёт письмо в почту.
   Ответ 2xx = успех; любой другой код или сетевая ошибка показывают состояние
   «не отправилось» со вторым путём — почтой. Введённое при этом не стирается.

2. В `assets/config.js`:

   ```js
   bookingEndpoint: "/api/booking",
   email: "ivan@troyanovsky.com"
   ```

3. Заменить плейсхолдеры `[ПОЧТА]` и `[ТЕЛЕФОН]` в `index.html`,
   `zayavka.html` и футере на реальные.

Занятые даты пока лежат в `assets/busy.js` — статический слепок в формате
будущего ответа сервера (DESIGN.md § 12). Источник (календарь, CRM или ручной
список) ещё не выбран, § 13.

## 5. Сколько это стоит клиенту

Считайте по своим цифрам, тарифы Selectel меняются — сверьтесь с прайсом перед
разговором. Порядок величин: хранение нескольких десятков мегабайт — копейки,
основная статья — исходящий трафик CDN. Формула простая:

```
трафик в месяц ≈ размер видео × число посетителей
```

При текущих 1,3 МБ и, скажем, 3000 посетителях в месяц это ~4 ГБ. Держите
видео лёгким — это прямее всего влияет на счёт. Полезные приёмы:

- `preload="metadata"` вместо `auto`, если решите, что автостарт не нужен;
- ограничить длину 10–15 секундами (сейчас 13);
- не поднимать битрейт выше нужного: кадр на первом экране обрезается `cover`,
  разрешение выше 1600px по длинной стороне зритель не увидит.

## 6. Что проверить после первого деплоя

- Видео стартует и зацикливается в Chrome, Safari и на iPhone.
- Шапка над видео читается, после первого экрана становится чёрной.
- Наведение на кадр — приближение и наклон (§ 7.9); на телефоне эффекта нет
  и не должно быть.
- Список историй: картинка идёт за курсором, соседние строки гаснут.
- Ничего не уезжает вбок на 375px.
- `prefers-reduced-motion` (в macOS — «Уменьшение движения»): маски
  выключаются, страница остаётся читаемой.
- Заявка: четыре шага проходятся, календарь листается стрелками с клавиатуры,
  занятые даты не нажимаются, пустые поля дают чёрную линейку и подпись,
  заявка реально приходит на почту (§ 4), а не только показывает «Спасибо».
